The risk score is a real scikit-learn Random Forest model (trained in Python, exported to pure JavaScript — see bhurakshak_ml_model.js logic inline above) running entirely client-side, no server needed. Rainfall/humidity are live via Open-Meteo; soil moisture, vibration and 7-day rainfall are simulated pending physical IoT sensors — see fetchLiveData() in source. In production: this same model can run on-device (edge AI) on a Raspberry Pi/ESP32 at each sensor node — so it keeps working with zero connectivity. Click "Network" top-right to simulate a no-network zone and see the alert cascade fall back to LoRa mesh + local siren. Wire triggerAlert() to Twilio (SMS), a LoRa gateway, and Firebase (cloud sync) for production deployment.
